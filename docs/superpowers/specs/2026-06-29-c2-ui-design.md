# 역대 C2 데이터 UI 노출 설계

작성: 2026-06-29 · 상태: 승인 대기

## 목적
역대 C2서 적재한 3종 데이터를 앱/웹에 노출. 데이터 준비 완료(크롤 불요, 순수 BE 쿼리/계산 + FE).
- **T1** 2군 시즌스탯 `historical_futures_season_stats` (12967행/17시즌, 타자7065+투수5389)
- **T3** 1군 스플릿 세밀축 `historical_splits` (타자 11130 / 투수 5459) — 투수 스플릿·좌우 플래툰·구장 축 신규
- **T2** 2군 경기 box `futures_games`+`futures_game_box` (952경기, 라인스코어+선수box+요약 JSONB)

## 범위 (사용자 게이트 확정)
- 전부 3종. 2군 box = **독립 퓨처스 화면**, 진입 = **순위 탭**.

---

## 컴포넌트 A — 선수상세 2군 시즌스탯

### 데이터/API
- 소스: `historical_futures_season_stats` WHERE kbo_player_id.
- `_career_extras(cur, kbo_player_id)` 번들에 `"futures_stats"` 키 추가 (현역·은퇴 공통 — 둘 다 이 번들 경유).
  - 신규 헬퍼 `_futures_stats(cur, kbo_player_id)`: 시즌 DESC 행 반환. 컬럼 = season, team_name, player_type, games + 타자(avg/home_runs/rbis/ops/sb) + 투수(era/innings_pitched/whip/wins/saves/strikeouts_pitched). NULL은 그대로(타자/투수 구분은 player_type).
- 현역 경로: `GET /players/{id}/career-extras` (player_id→kbo 브릿지). 은퇴: `GET /historical/{kbo_id}/career-extras`. **둘 다 `_career_extras` 호출하므로 헬퍼 1곳 수정으로 양쪽 반영**.

### UI
- 공유 위젯 `CareerExtrasSection`에 "2군 기록" 블록 추가 (`_futuresBlock`). 빈값(`futures_stats` 비었음) → `SizedBox.shrink()` 자동숨김.
- 표 형태: 시즌별 행. 타자 = 시즌|팀|G|AVG|HR|OPS / 투수 = 시즌|팀|G|ERA|IP|WHIP. player_type로 컬럼셋 분기.
- 위치: 기존 career-extras 카드 내(타이틀/팀변천/마일스톤/스플릿과 동급 블록).

### 한계 (의도)
- 브릿지 안 된 신규 현역(kbo_player_id 없음)은 2군 기록 미표시. 데이터 한계, graceful 숨김.

## 컴포넌트 B — 선수상세 스플릿 세밀축 확장

### 데이터/API
- ⚠️ 현 `_player_splits`는 **타자 컬럼만 SELECT**(avg/slg/home_runs/rbis/at_bats/hits) → 투수행은 전부 NULL → UI 미표시. **수정 필수**:
  - SELECT에 `player_type, era, innings_pitched, whip, strikeouts_pitched, walks_allowed, hits_allowed` 추가.
  - 반환 행에 `player_type` + 투수 메트릭 포함.
- ⚠️ DB `split_axis` = 한글값(`홈원정`/`상대팀`/`월별`/`투수유형`/`구장`/`타자유형`). 현 Dart `axisLabels`(영문키)는 매칭 실패 → raw 폴백 표시 중. 확장 시 한글축 직접 라벨맵.

### UI (`_splitsBlock` 확장)
- **투수 스플릿 렌더**: player_type별 분기. 투수 칩 = **ERA 표시**(대표 메트릭, 현 타자는 AVG). 집계 = value별 `earned_runs`·`innings_pitched` 누적 → ERA = er×9/ip_real (ip .1/.2=⅓⅔ 환산, 기존 패턴). er/ip 없으면 칩 제외.
- **축 라벨맵**(한글축 직접): `홈원정`→"홈/원정", `상대팀`→"상대팀별", `월별`→"월별", `투수유형`→"vs 좌/우투(플래툰)", `구장`→"구장별", `타자유형`→"vs 좌/우타".
- **플래툰 강조**: 투수유형/타자유형 축 = 좌우 split, 가장 분석가치 높은 축 → 블록 상단 우선 정렬. `split_value`는 **KBO 제공값 그대로 표시**(좌/우 라벨 하드코딩 불요).
- 타자/투수 둘 다 있는 선수(투타겸업 드묾) = player_type별 분리 표기.

### 한계 (의도)
- 투수 스플릿 2024~2025만(2026 = 1군 season_stats 상한 2025라 pid맵 부재로 미적재). 타자 = 2023~2026.
- OBP/OPS 스플릿 = Basic1 split에 BB 없어 미수집.

## 컴포넌트 C — 독립 퓨처스 화면

### API (신규 라우터 `api/routers/futures.py`)
- `GET /futures/games?season=&month=` — 일정/결과. `futures_games` WHERE season(+month) ORDER BY game_date. 반환 = game_id, game_date, away_code/home_code, away_score/home_score, stadium, status, series_id, has_box(box 존재 여부). @cached(300).
- `GET /futures/games/{game_id}/box` — box 상세. `futures_game_box` JSONB(scoreboard/away_batters/home_batters/pitchers/summary) + futures_games 메타. @cached(3600).
- `GET /futures/leaders?season=` — 2군 시즌스탯 TOP (보너스). `historical_futures_season_stats` 부문별(타자 avg/hr/rbi·투수 era/w/sv) TOP. 규정 게이트 없음(2군은 표본 작음, 전체 정렬). @cached(3600).
- 팀코드 → 팀명/로고 매핑: 기존 teams 매핑 + 2군 전용(상무 SM·고양 WO·울산 UL·소프트뱅크 SO 교류전) 라벨 상수.

### UI (`screens/futures/futures_screen.dart` 신규)
- 진입: **순위 탭**(team_screen)에 "퓨처스" 진입(역대기록실 진입 패턴 동류 — 버튼/탭).
- 구성:
  - 상단 월 네비(연/월 픽커, 기본 = 최근 데이터 월).
  - 날짜별 경기 리스트: 셀 = 양팀 로고/코드 + 스코어 + 상태(종료/취소) + 구장. 교류전(series_id=10, 소프트뱅크 등) 배지.
  - 셀 탭 → box 시트(bottom sheet): 라인스코어(1-9 R/H/E) + 타자 box(타순/위치/이름/타수/안타/타점/타율) + 투수 box(이름/결과/IP/H/ER/SO/ERA) + 요약(결승타/홈런/실책).
  - (보너스) 상단 토글로 "2군 기록실"(leaders) = 부문별 TOP 리스트.
- ⚠️ box 선수 = **이름만**(playerId 없음) → 선수상세 링크 없음(plain text). 웹 안전(이미지無).

### 진입점 상세 (확정)
- `team_screen.dart` 순위 탭 TabBar = 현 팀순위/팀기록/부문별순위/역대기록실(length4 isScrollable). → **5번째 탭 "퓨처스" 추가**(length5, isScrollable이라 수용). 탭 내용 = `FuturesScreen` 위젯(또는 그 본문 위젯). 역대기록실이 탭화된 선례 그대로.

## 공통

### 웹 동반
- 전부 텍스트/표, 이미지 = 팀로고(netImage/TeamLogo 기존 웹안전 위젯). 신규 위젯 웹규칙 준수(netCircleAvatar/netImage, NetworkImage 금지).
- 재빌드+rsync `/var/www/playball_web/`, `/app/` 200 확인. analyze lib=0·골든 회귀.

### 토큰/스타일
- 신규 위젯 = Typo/Pal/SemColor/Radii/Space 토큰 우선(인라인 hex 금지). 기존 `_C`/career_extras 스타일 따름.

### 테스트
- BE 순수헬퍼(`_futures_stats`/box JSONB 가공) = pytest 순수테스트. 라이브 스팟체크(양현종 2군 무·이정후류 2군 기록 / 퓨처스 경기 box).
- analyze lib=0, 골든 회귀(share_cards 불변).

### 무관 변경 금지
- career-extras/_player_splits 수정은 C2 노출에 한정. 기존 타자 스플릿 표시 회귀 없게(축 라벨맵 보강은 기존 raw폴백 개선이라 안전).

## 순서 (가치/응집도)
1. 컴포넌트 B (스플릿 — API 작음, 기존 UI 확장, 高가치)
2. 컴포넌트 A (2군 시즌스탯 — career-extras 번들 확장)
3. 컴포넌트 C (퓨처스 화면 — 신규 라우터+화면, 가장 큼)
